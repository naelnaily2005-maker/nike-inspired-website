# Nike-Inspired E-commerce Website

This is the link to website : https://naelnaily2005-maker.github.io/nike-inspired-website/

Technologies: HTML, internal CSS

A personal front-end practice project inspired by Nike's visual style, focused on page layout, styling, and e-commerce interface design.

Website Features :

The website includes four main sections: Products, featuring men's and women's shoes; About Us, introducing the brand; Our History, highlighting its background; and Our Location, providing location information.

Future Improvements: This is an ongoing learning project, and I plan to improve its design, responsiveness, accessibility, and functionality as I continue developing my front-end skills.

Independent educational project inspired by Nike's visual style; not affiliated with or endorsed by Nike.
